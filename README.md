# Echoes of Ruin

Videojuego 2D de acción y mazmorras (Action-Roguelike) con vista superior,
desarrollado con Godot Engine 4 y GDScript como Trabajo Final de Grado de
Ingeniería Informática (UOC).

## Estado
Versión alpha (entrega PEC3). Jugable de principio a fin.

## Descargar y jugar
Descarga el ZIP de la última versión desde la sección
[Releases](../../releases), descomprímelo y abre `EchoesOfRuin.exe`.

## Controles
| Acción | Control |
| Moverse | W A S D |
| Apuntar | Ratón |
| Disparar | Clic izquierdo |
| Pausa | Escape |

## Características
- Generación aleatoria de salas.
- Enemigos con inteligencia artificial.
- Combate en tiempo real, vida e interfaz.
- Minimapa, menú de inicio, pausa y pantallas de victoria y derrota.

## Abrir el proyecto
1. Instalar [Godot Engine 4.7](https://godotengine.org/).
2. Clonar este repositorio e importar la carpeta desde el gestor de proyectos.
